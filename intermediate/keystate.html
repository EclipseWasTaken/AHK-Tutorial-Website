Mouse & Key State ⌨️

Hey there! When you write advanced automation or game macros, you often need to check what the user is physically doing. "Is the Shift key held down right now?", "Wait until the user releases the Left Mouse Button before clicking again." Let's look at how to monitor the real-time physical states of keys and mouse buttons.

1. Checking If a Key is Held Down (GetKeyState)

To inspect the state of a key at any moment, use GetKeyState(KeyName, Mode). By default, it checks the logical state. If you pass "P", it checks the Physical state—meaning whether the user is physically pressing the key on their keyboard right now!

; Check physical press state
^Space::
{
    if GetKeyState("Shift", "P") {
        MsgBox("You pressed Ctrl+Space while physically holding Shift!")
    } else {
        MsgBox("You pressed Ctrl+Space without Shift.")
    }
}

2. Toggled States (Caps Lock, Num Lock, Scroll Lock)

You can also check whether toggle keys are currently ON or OFF by passing "T" as the second argument. This is perfect for setting states in macros.

; Check if CapsLock is toggled on
if GetKeyState("CapsLock", "T") {
    MsgBox("Warning: CapsLock is currently ON!")
}

3. Pausing Until a Key is Released (KeyWait)

The KeyWait(KeyName, Options) function is a powerful sync tool. It pauses your script until a specific key is released or pressed. This prevents macros from double-triggering or clicking too early.

; Double-Click Macro: Waits until Left Click is released, then double clicks
$LButton::
{
    ; Pass the click through by sending it, but wait for the physical release
    Send("{LButton Down}")
    KeyWait("LButton") ; Pauses script here until the user physically lets go!
    Send("{LButton Up}")
    
    ; Immediately click again! (Double click)
    Click()
}
💡 My KeyWait Time-Out Trick

By default, KeyWait pauses the script indefinitely. But you can pass "T[Seconds]" in the options to set a timeout! If the key is not released/pressed within that timeframe, it returns 0 instead of 1. This prevents your script from hanging forever:

; Wait up to 3 seconds for the user to press the Enter key
if KeyWait("Enter", "D T3") { ; "D" means wait for key to go DOWN
    MsgBox("Enter was pressed within 3 seconds!")
} else {
    MsgBox("Enter was not pressed in time.")
}
