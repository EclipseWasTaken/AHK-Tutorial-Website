Timers & SetTimer ⏱️

Hey! In this lesson, we are going to look at one of the absolute best architectural functions in AutoHotkey: SetTimer. Timers allow you to run code asynchronously in the background on a schedule. This is crucial for keeping your scripts responsive.

Why You Should Stop Using Sleep Loops

🚨 The "Frozen Script" Mistake

Many beginners write background checking loops like this:

Loop {
    CheckWindow()
    Sleep(5000) ; Sleep for 5 seconds
}

The problem: During that Sleep period, your script is completely frozen. Other hotkeys might lag or fail to trigger, and GUIs will become unresponsive. Sleep blocks the entire thread.

The solution: Use SetTimer()! It schedules a function to run at intervals without blocking any other code in your script.

1. Setting Up a Repeating Background Timer

To start a repeating timer, call SetTimer(FunctionName, PeriodMs). To turn it off, pass a period of 0.

; Check for an unwanted popup every 2 seconds
SetTimer(CloseWarningPopup, 2000)

CloseWarningPopup() {
    if WinExist("Warning - Unsafe File") {
        WinClose() ; Close the popup
        SoundBeep(800, 100) ; Sound alert
        
        ; Optional: Stop the timer if it only needed to run once
        ; SetTimer(CloseWarningPopup, 0)
    }
}

2. One-Shot Timers (Delays Without Freezing)

Sometimes you don't want a repeating timer; you just want to delay an action without freezing the UI. To do this, pass a negative number as the period. This tells AHK to run the function exactly *once* after that delay.

; Trigger a keypress, but schedule a cleanup task 3 seconds later without freezing
^s::
{
    MsgBox("Triggered! The cleanup will occur in 3 seconds in the background.")
    ; Run CleanUp exactly once in 3000ms
    SetTimer(CleanUp, -3000)
}

CleanUp() {
    MsgBox("CleanUp executed asynchronously!")
}

3. Working with Closures / Fat Arrows

What if you want to pass arguments to a timer callback? You can use a nested function or a fat-arrow lambda function! This is incredibly sleek in AHK v2:

AnnounceMessage(msg, delay) {
    ; Schedule an anonymous function to show the message
    SetTimer( () => MsgBox(msg), -delay )
}

; Call it! Shows "Hello" in 1.5 seconds, but returns immediately
AnnounceMessage("Hello from 1.5s ago!", 1500)
