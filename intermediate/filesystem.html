File System Operations

AHK can read from and write to files, check if files exist, create folders, and scan directories. This lets you build scripts that log data, load configuration, process text files, and much more.

Intermediate

FileExist() — Check if a file or folder exists

Before reading or writing, always check if the file is there. FileExist() returns an attribute string if found, or an empty string (falsy) if not.

; I always check if a file exists before doing anything
if FileExist("C:\logs\output.txt")
{
    MsgBox("File found!")
}
else
{
    MsgBox("File does not exist.")
}

; Check if a folder exists
if FileExist("C:\MyFolder")
{
    MsgBox("Folder exists!")
}

; Use it in-line (cleaner)
logExists := FileExist("C:\logs\app.log") != ""
MsgBox("Log present: " . logExists)
Attribute string

FileExist() returns a string like "A" (Archive), "D" (Directory), "R" (Read-only), etc. For a simple existence check, just test it as a boolean — empty string is falsy, any non-empty string is truthy.

FileRead() — Read a file into a variable

FileRead() loads the entire contents of a text file into a string. Perfect for reading config files, lists, or log data.

; Read a file and display its contents
content := FileRead("C:\notes.txt")
MsgBox(content)

; I highly recommend checking if it exists first (best practice)
if FileExist("C:\config.txt")
{
    data := FileRead("C:\config.txt")
    MsgBox("Config loaded: " . data)
}
else
{
    MsgBox("Config file missing!")
}

; Process a list — split by newline
lines := StrSplit(FileRead("C:\words.txt"), "`n")
For i, line in lines
{
    MsgBox("Line " . i . ": " . line)
}
Backtick escapes in AHK strings

In AHK v2, the backtick ` is the escape character inside strings. So a newline is `n, a tab is `t, and a carriage return is `r. Windows files often use `r`n (CRLF) as line endings.

FileAppend() — Write text to a file

FileAppend() adds text to the end of a file. If the file doesn't exist, it creates it. This is ideal for logging — each call adds a new entry without erasing old ones.

; Write a single line to a log file
FileAppend("Script started.`n", "C:\log.txt")

; Append with a timestamp
timestamp := FormatTime(, "yyyy-MM-dd HH:mm:ss")
FileAppend(timestamp . " — Script ran`n", "C:\log.txt")

; Log a variable value
score := 42
FileAppend("Score: " . score . "`n", "C:\results.txt")

; Write multiple lines at once
FileAppend("Line 1`nLine 2`nLine 3`n", "C:\output.txt")

FileDelete() — Delete a file

Use FileDelete() to remove a file. Wildcards are supported for batch deletion.

; Delete a single file
FileDelete("C:\old_log.txt")

; Delete all .tmp files in a folder
FileDelete("C:\Temp\*.tmp")

; What I suggest (check file exists):
if FileExist("C:\cache.dat")
{
    FileDelete("C:\cache.dat")
    MsgBox("Cache cleared!")
}

DirCreate() — Create a folder

DirCreate() makes a new directory. It creates all intermediate parent directories automatically, like mkdir -p in Linux.

; Create a single folder
DirCreate("C:\MyApp\logs")

; Create nested folders in one call
DirCreate("C:\Projects\AHK\scripts\utils")

; What I suggest (Only create if it doesn't exist)
if !FileExist("C:\MyApp\output")
{
    DirCreate("C:\MyApp\output")
    MsgBox("Output folder created!")
}

More File Functions

FunctionWhat it does
FileCopy(src, dest)Copies a file to a new location
FileMove(src, dest)Moves (or renames) a file

Real-World Example — Session Logger

#Requires AutoHotkey >= 2.0
#SingleInstance Force

logFile := A_ScriptDir . "\session.log"

; We need to make sure the log folder exists
DirCreate(A_ScriptDir)

; On start, write a session entry
startTime := FormatTime(, "yyyy-MM-dd HH:mm:ss")
FileAppend("=== Session started: " . startTime . " ===`n", logFile)

; Ctrl+L → show the log contents
^l::
{
    if FileExist(logFile)
    {
        content := FileRead(logFile)
        MsgBox(content)
    }
    else
        MsgBox("No log yet!")
}

; Ctrl+Shift+L → clear the log
^+l::
{
    if FileExist(logFile)
    {
        FileDelete(logFile)
        MsgBox("Log cleared!")
    }
}
⚠️ Paths and Backslashes

In AHK v2 strings, the backslash \ is not an escape character (unlike many languages). So "C:\folder\file.txt" works exactly as written — no need to double the backslashes. Only the backtick ` is special inside AHK strings.
