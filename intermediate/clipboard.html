Clipboard Automation 📋

Hey there! One of the absolute fastest ways to automate office tasks, data entry, and text processing is by leveraging the Windows Clipboard. AutoHotkey v2 makes reading, writing, and monitoring the clipboard incredibly simple.

1. Read and Write Text Directly

The built-in variable A_Clipboard gives you direct access to the clipboard. You can read it or assign to it just like any other variable!

; Write to clipboard
A_Clipboard := "Hello from AutoHotkey!"

; Read from clipboard
MsgBox("Clipboard currently holds: " . A_Clipboard)

2. The "Rookie Trap" & ClipWait

⚠️ The Race Condition Bug

A very common bug is sending a copy command (^c) and immediately trying to read A_Clipboard. Windows takes a fraction of a second to load the copied data into memory. If your script runs faster than Windows, it will read old data or crash!

The Fix: Always clear the clipboard first, send the copy shortcut, and then call ClipWait() to wait for Windows to finish copying.

CopySelectedText() {
    A_Clipboard := "" ; Step 1: Clear the clipboard so ClipWait can detect change
    Send("^c")        ; Step 2: Trigger Ctrl+C
    
    ; Step 3: Wait up to 1 second for text to arrive
    if !ClipWait(1) {
        MsgBox("Copy failed or nothing was selected!")
        return ""
    }
    return A_Clipboard
}

3. Backup and Restore the Clipboard (Polite Scripts)

If your script copies and pastes text in the background, it's very annoying for users if it overwrites what they had copied (like a link or text they were working on). A polite script backs up their clipboard, does its work, and restores it afterwards using ClipboardAll()!

; Create a hotkey that wraps selected text in double-quotes
^q::
{
    ; Backup everything (including formatting/images!)
    clipBackup := ClipboardAll()
    
    ; Perform copy
    A_Clipboard := ""
    Send("^c")
    if ClipWait(1) {
        ; Wrap the text and paste it back
        A_Clipboard := '"' . A_Clipboard . '"'
        Send("^v")
        Sleep(100) ; Give Windows a tiny bit of time to paste
    }
    
    ; Restore original clipboard!
    A_Clipboard := clipBackup
}
