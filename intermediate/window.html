Window Management

AHK can control any window on your system — bring it to focus, wait for it to open, resize it, close it, or check if it exists. This makes it perfect for automating multi-app workflows.

Intermediate

How AHK Identifies Windows

Every function that works with windows needs a way to identify which window you mean. AHK uses WinTitle expressions for this. The most common ones are:

ExpressionMeaningExample
"A"The currently active (foreground) windowWinClose("A")
"Notepad"Any window whose title contains "Notepad"WinActivate("Notepad")
"ahk_exe notepad.exe"Window owned by a specific process nameWinExist("ahk_exe chrome.exe")
"ahk_class Notepad"Window with a specific class nameWinActivate("ahk_class Notepad")
"ahk_pid 12345"Window by process IDAdvanced use
How do You find these values?

Open any AHK script, right-click the green tray icon → Open Window Spy. Hover over any window and it shows you the title, class, and exe name in real time. This is your best friend for window automation.

WinExist() — Does this window exist?

Before doing anything to a window, it's good practice to check if it's actually open. WinExist() returns a non-zero window handle if found, or 0 (falsy) if not.

; Check if Notepad is open
if WinExist("Notepad")
{
    MsgBox("Notepad is running!")
}
else
{
    MsgBox("Notepad is not open.")
}

; More reliable: match by exe name
if WinExist("ahk_exe notepad.exe")
{
    MsgBox("Found Notepad by process name!")
}

WinActivate() — Bring a window to focus

WinActivate() brings the specified window to the foreground, making it the active window. Think of it like clicking on a window in the taskbar.

; I'm bringing Notepad to the front
WinActivate("Notepad")

; Bring Chrome to the front by exe name
WinActivate("ahk_exe chrome.exe")

; Hotkey: Win+N → open or focus Notepad
#n::
{
    if WinExist("ahk_exe notepad.exe")
        WinActivate("ahk_exe notepad.exe")
    else
        Run("notepad.exe")
}

WinWaitActive() — Wait until a window is focused

Sometimes you tell a window to activate, but it takes a moment to come forward (especially if it's loading). WinWaitActive() pauses your script until the window is actually in the foreground.

; I'll tell Notepad to activate, then wait for it
WinActivate("Notepad")
WinWaitActive("Notepad")  ; blocks until Notepad is in front
Send("Hello Notepad!")       ; safe to type now

; With timeout: wait up to 3 seconds
WinActivate("Calculator")
if !WinWaitActive("Calculator", , 3)
{
    MsgBox("Calculator didn't come up in time!")
    return
}
Send("123+456=")
🕐 The timeout parameter

WinWaitActive(Title, Text, Timeout) — the third argument is how many seconds to wait before giving up. If no timeout is specified, it waits forever. Always use a timeout in production scripts so they don't hang permanently.

WinWait() — Wait for a window to exist

Use WinWait() when you're launching an app and need to wait for its window to first appear (it might not be active yet).

; First I launch Notepad, then wait for its window to open
Run("notepad.exe")
WinWait("ahk_exe notepad.exe")   ; waits for the window to exist
WinActivate("ahk_exe notepad.exe")  ; now bring it to front
WinWaitActive("ahk_exe notepad.exe") ; ensure it's in foreground
Send("Automated typing in Notepad!")

WinClose() — Close a window

WinClose() sends a close request (like clicking the X button). WinKill() forcibly terminates the process if needed.

; Gracefully close Notepad (may ask to save)
WinClose("Notepad")

; Force-kill a process if it won't close
WinKill("ahk_exe notepad.exe")

; Close the currently active window (like Alt+F4)
WinClose("A")

Real-World Example — Launch & Automate App

#Requires AutoHotkey >= 2.0
#SingleInstance Force

; Ctrl+F2: Open Notepad, wait for it, type a note
^F2::
{
    ; Launch Notepad
    Run("notepad.exe")

    ; Wait up to 5 seconds for it to open
    if !WinWait("ahk_exe notepad.exe", , 5)
    {
        MsgBox("Notepad failed to open!")
        return
    }

    WinActivate("ahk_exe notepad.exe")
    WinWaitActive("ahk_exe notepad.exe", , 3)

    ; Maximize and type content
    WinMaximize("A")
    SendText("Meeting notes - ")
    Send(A_Now)   ; Insert current timestamp
    Send("{Enter 2}")
    SendText("TODO:")
}
