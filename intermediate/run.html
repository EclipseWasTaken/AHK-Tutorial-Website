Run & Processes 🚀

Hey! In this lesson, we will look at how to control external applications. Running other programs, opening websites, checking if an app is currently open, and closing frozen windows are core tasks in any serious automation workflow.

1. Launching Programs & URLs (Run)

The Run() function launches applications, documents, folders, or web links. You can also specify the working directory or parameters.

; Launch Notepad
Run("notepad.exe")

; Launch a website in your default browser
Run("https://www.autohotkey.com")

; Launch with parameters (e.g. open a specific text file)
Run('notepad.exe "C:\myFolder\log.txt"')

; Run an app maximized
Run("calc.exe", , "Max")

2. Waiting for Completion (RunWait)

Sometimes, your script needs to run a tool (like a console command or installer) and wait for it to finish *before* executing the next line of code. For this, use RunWait().

; Open Calc, and pause script execution until Calc is closed by the user
RunWait("calc.exe")
MsgBox("Calculator was closed! Now running the next command.")

3. Process Checking and Terminating

Need to check if a program is active in the background, or force close it if it freezes? Use ProcessExist() and ProcessClose().

; Check if Google Chrome is running
if ProcessExist("chrome.exe") {
    MsgBox("Chrome is open!")
} else {
    MsgBox("Chrome is NOT running.")
}

; Force terminate a specific process
^!t::
{
    if ProcessExist("notepad.exe") {
        ProcessClose("notepad.exe")
        MsgBox("Force closed Notepad!")
    }
}

4. Running as Administrator (UAC elevation)

💡 My Admin Tip

If your script needs to click inside elevated programs (like Task Manager, Registry Editor, or certain video games), AHK will be blocked by Windows User Account Control (UAC) unless the script itself is running as Administrator!

Add this simple block at the top of your script to automatically relaunch it with Administrator privileges:

if !A_IsAdmin {
    Run('*RunAs "' . A_ScriptFullPath . '"')
    ExitApp()
}
