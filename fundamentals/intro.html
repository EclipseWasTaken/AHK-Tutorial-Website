AutoHotkey v2 is a free, open-source scripting language for Windows. Remap keys, automate repetitive tasks, build GUIs, and control any app.

Free & Open Source Windows Only v2.0 — Cleaner Syntax

Why AHK v2?

⚡ Instant Automation

Turn any repetitive task into a single keypress. Text expansion, form filling, app launching.

Deep Windows Integration

Control windows, processes, registry, files, and other apps via COM objects.

Mouse & Keyboard Control

Simulate any keyboard or mouse input. Remap any key to do anything.

Build Real GUIs

Create Windows GUI apps with buttons, inputs, dropdowns — no extra framework needed.

🔄 v1 vs v2 — Key Changes

AHK v2 intentionally breaks v1 compatibility to fix design flaws. Key changes: use := for all assignments, no more %var% dereferencing (use var directly), functions always need parentheses, fat-arrow syntax =>, and proper class system. This guide covers v2 only.

Your first script

; Save as MyScript.ahk or wtv and double-click to run
#Requires AutoHotkey >= 2.0
#SingleInstance Force

; Ctrl+J — show a message
^j::
{
    MsgBox("Hello from AHK v2!")
}

; Ctrl+Shift+R — reload script
^+r::
{
    Reload()
}

; Ctrl+Shift+Q — quit
^+q::
{
    ExitApp()
}
💡 Pro Tip

Always include a quit hotkey (^+q) and reload hotkey (^+r) in every script. It saves enormous frustration when testing.

Installing

  • Download from autohotkey.com — choose v2
  • Run the installer with default options
  • Right-click Desktop → New → AutoHotkey Script
  • Double-click the .ahk file to run it
  • Look for the green tray icon — that means it's running
