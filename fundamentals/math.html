The Division Trap (Float vs. Integer)

💡 Pay Attention Here!

A huge trap for beginners in AHK v2 is how division works. Unlike older versions, division in v2 is clean but has two distinct operators:

  • Standard Division (/): Always returns a floating-point number (decimal), even if they divide perfectly. E.g. 4 / 2 is 2.0.
  • Integer Division (//): Discards the decimal part entirely. E.g. 5 // 2 is 2.
; Let's see it in action!
x := 5
y := 2

floatDiv := x / y   ; 2.5
intDiv   := x // y  ; 2
remainder := Mod(x, y) ; 1 (Modulo operator)

MsgBox("Float: " . floatDiv . "`nInteger: " . intDiv . "`nRemainder: " . remainder)

Essential Math Functions

Here are the common math functions I use in my scripts almost every day. Try running them in the Playground!

Function What it does Example
Abs(n) Returns absolute value (removes negative sign) Abs(-5) ➜ 5
Round(n, precision) Rounds to nearest integer or decimal places Round(3.14159, 2) ➜ 3.14
Floor(n) Rounds down to nearest integer Floor(3.8) ➜ 3
Ceil(n) Rounds up to nearest integer Ceil(3.1) ➜ 4
Random(min, max) Generates a random integer between min and max Random(1, 100)

Dynamic Delays (Game & Web Automation)

If you are writing scripts to automate actions (like clicking or typing), static delays (like Sleep(1000)) make your script look like a bot. I always use Random() to add human-like variation:

; Perform a human-like click with a randomized delay
Click()
; Sleep anywhere between 150ms and 450ms
sleepTime := Random(150, 450)
Sleep(sleepTime)
Send("Hello!")
