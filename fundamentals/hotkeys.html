Hotkeys

Hotkeys are the heart of AutoHotkey. Trigger code with any key combination.

Modifier Symbols

SymbolKeyExample
^Ctrl^c = Ctrl+C
!Alt!Tab = Alt+Tab
+Shift+F4 = Shift+F4
#Win key#d = Win+D
*Wildcard (any modifier)*a
~Passthrough (native also fires)~^c
$Hook (prevents Send recursion)$^c
 
; These are basic hotkeys
^j::
{
    MsgBox("Ctrl+J pressed!")
}

!F4::
{
    WinClose("A")  ; "A" = active window
}

; Single-line hotkey
#Space:: Run("notepad.exe")

; Remap one key to another
CapsLock::Ctrl

; Context-sensitive
#HotIf WinActive("ahk_exe notepad.exe")
^s::
{
    Send("This only works in Notepad!")
}
#HotIf

Hotstrings

; Type "btw" then space/enter → expands
::btw::"by the way"

; Hotstring with code block
::sig::
{
    Send("John Doe{Enter}john@example.com{Enter}555-1234")
}

; * = fires immediately, no end char needed
:*:teh::"the"

; r = raw (no special key parsing)
:r:html::"<html></html>"
