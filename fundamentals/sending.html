Sending Keystrokes & Clicks

AHK can simulate anything a human can type or click — pressing keys, holding modifiers, moving the mouse, and clicking buttons in other apps. This is one of AHK's most powerful features.

The Three Send Modes

There are three versions of Send. Knowing when to use each one matters:

FunctionWhat it doesBest for
Send()Sends keystrokes interpreting special keys like {Enter}Most situations
SendText()Sends text literally — no special key parsingTyping strings with symbols like ! or ^
SendInput()Fastest and most reliable mode, same syntax as SendSpeed-critical scripts
💡 Why does this matter?

With Send(), the ! character means Alt. So Send("!f") presses Alt+F, not the letter "!f". If you just want to type an exclamation mark, use SendText("!") instead.

Sending Plain Text

; Let's type a greeting into whatever is focused
Send("Hello, World!")

; I suggest using SendText as it's safer for special characters
SendText("Price: $9.99 (50% off!)")

; Practical: auto-fill an email signature
^+s::   ; Ctrl+Shift+S
{
    Send("Best regards,{Enter}John Doe{Enter}john@example.com")
}

Special Key Names Inside { }

Any key that isn't a normal letter or number needs to be wrapped in { } curly braces inside a Send string.

What you writeWhat key it sends
{Enter}The Enter / Return key
{Tab}The Tab key
{Space}Spacebar (use when spaces get trimmed)
{Backspace}Delete the character to the left
{Delete}The Delete key
{Escape}Escape / Esc
{Up} {Down} {Left} {Right}Arrow keys
{Home} {End}Home / End keys
{F1} – {F12}Function keys
{PgUp} {PgDn}Page Up / Page Down
{PrintScreen}Print Screen

Modifier Keys (Ctrl, Alt, Shift, Win)

Inside a Send string, modifier keys use the same shorthand symbols as hotkey definitions:

SymbolModifier keyExampleWhat it does
^Ctrl^cCtrl+C (copy)
!Alt!{F4}Alt+F4 (close window)
+Shift+{Tab}Shift+Tab (go backwards)
#Win key#dWin+D (show desktop)
 
; Select all text and copy it
Send("^a")   ; Ctrl+A
Send("^c")   ; Ctrl+C

; Open a new browser tab
Send("^t")   ; Ctrl+T

; Alt+F4 closes the active window
Send("!{F4}")

; Type "Hello" with a capital H (Shift+h)
Send("+h")
Send("ello")

Repeating a Key Multiple Times

You can press a key N times in one Send call using the syntax {KeyName N}:

; Press the down arrow 5 times
Send("{Down 5}")

; Delete 10 characters
Send("{Backspace 10}")

; Press Tab 3 times to jump 3 fields in a form
Send("{Tab 3}")

; Hold Shift while pressing Right 5 times (selects 5 chars)
Send("+{Right 5}")

Holding Keys Down & Releasing

Use {KeyName down} and {KeyName up} to hold a key pressed across multiple other keystrokes:

; We hold Alt, press Tab twice, then release Alt to cycle 2 windows
Send("{Alt down}{Tab}{Tab}{Alt up}")

; Hold Shift and click three keys (select a range)
Send("{Shift down}{End}{Shift up}")  ; select to end of line
💡 Good to know

Always pair every {key down} with a {key up}! If your script crashes in between, the key stays "stuck" down until you press it physically. Use Send("{key up}") in your hotkey's cleanup or try/catch to be safe.

Mouse Clicks with Click()

Click() simulates a mouse click. You can specify coordinates, the button, and how many times to click.

; Left-click at screen coordinates (100, 200)
Click(100, 200)

; Right-click at (500, 300)
Click(500, 300, "Right")

; Double-click
Click(200, 400, "Left", 2)   ; 4th arg = click count

; Click without moving the mouse (clicks current position)
Click()

; Left-click and hold (mouse down only)
Click(300, 300, "Left", 1, "Down")
Sleep(500)
Click(300, 300, "Left", 1, "Up")

Moving the Mouse with MouseMove()

MouseMove() glides the cursor to a position. The optional speed parameter (0–100) controls how fast it moves — 0 is instant, 2 is the default.

; Move to (800, 400) at default speed
MouseMove(800, 400)

; Move instantly (speed = 0)
MouseMove(100, 100, 0)

; Move slowly (speed = 10, more human-like)
MouseMove(600, 300, 10)

; Move relative to current position
MouseMove(50, 0, 2, "Relative")  ; 50px to the right

Real-World Example — Auto Form Filler

#Requires AutoHotkey >= 2.0
#SingleInstance Force

; Press Ctrl+F1 to fill in a form automatically
^F1::
{
    ; Click the Name field
    Click(400, 200)
    Sleep(100)
    SendText("Jane Smith")

    ; Tab to next field
    Send("{Tab}")
    Sleep(100)
    SendText("jane@example.com")

    ; Tab to phone number
    Send("{Tab}")
    Sleep(100)
    SendText("555-0100")

    ; Press Enter to submit
    Send("{Enter}")
}
⚠️ Coordinate Gotcha

Screen coordinates are measured from the top-left corner of your primary monitor. X increases going right, Y increases going down. If you have multiple monitors, coordinates can be negative or very large. Use AHK's built-in Window Spy tool (in the tray icon menu when AHK is running) to find exact pixel coordinates on your screen.
