Basic Syntax

AHK v2 cleaned up v1's messy syntax. Here's what you need to write valid code.

Comments

; Single-line comment
/*
   Multi-line
   comment
*/

x := 5  ; Inline comment after code

Assignments & Expressions

name    := "Alice"
age     := 30
isAdmin := true
pi      := 3.14159

; Compound operators
count := 0
count++          ; count = 1
count += 9        ; count = 10
count *= 2        ; count = 20

; String concatenation uses a dot
greeting := "Hello, " . name  ; "Hello, Alice"

Function Calls

; v2 ALWAYS uses parentheses for calls
MsgBox("Hello World")
Sleep(1000)
Send("{Enter}")
result := StrLen(name)

; MsgBox with title and buttons
MsgBox("Are you sure?", "Confirm", "YesNo")

Auto-Execute Section

⚠️ Important

Code at the top of the script (before any hotkey definitions) runs once on startup. Put initialization, #Requires, and #SingleInstance here.

; Auto-execute (runs on startup)
#Requires AutoHotkey >= 2.0
#SingleInstance Force

MsgBox("Script started!")
myVar := "initialized"

; Hotkeys below
^h::
{
    MsgBox(myVar)
}
