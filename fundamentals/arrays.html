Arrays Deep Dive 🎒

Hey! In this lesson, we are going to dive deep into Arrays. Arrays are lists of items, and they are used absolutely everywhere in scripting. Since they are so critical, you need to master how to add, remove, search, and loop through them cleanly.

⚠️ CRITICAL REMINDER: Arrays are 1-Indexed!

I have to repeat this because it's the number one mistake developers make when coming to AHK from languages like JS or Python: AutoHotkey arrays start at index 1. The first element is myArray[1], and the last is myArray[myArray.Length]!

1. Manipulating Arrays (Push, Pop, InsertAt, RemoveAt)

Here is how you add and remove elements from anywhere in an array. Let's look at the basic operations:

; Create a fresh array
todo := ["Clean Room", "Code AHK"]

; 1. Push: Add to the very end
todo.Push("Read Docs") ; ["Clean Room", "Code AHK", "Read Docs"]

; 2. Pop: Remove and return the last item
lastTask := todo.Pop() ; Removes "Read Docs" and returns it

; 3. InsertAt: Insert at a specific position (shifts everything else right)
todo.InsertAt(1, "Wake Up") ; ["Wake Up", "Clean Room", "Code AHK"]

; 4. RemoveAt: Remove from a specific position (shifts everything left)
todo.RemoveAt(2) ; Removes "Clean Room" ➜ ["Wake Up", "Code AHK"]

MsgBox("Tasks left: " . todo.Length . "`nFirst: " . todo[1])

2. Loop Patterns (How to Traverse Lists)

There are two primary ways I loop through arrays. The For Loop is standard, but sometimes a classic Index Loop is useful if you need to modify elements on the fly.

fruits := ["Apple", "Banana", "Cherry"]

; Pattern A: The For-Each Loop (Standard & Cleanest)
for index, fruit in fruits {
    MsgBox("Fruit #" . index . " is: " . fruit)
}

; Pattern B: Length Loop (Useful if you need index-based calculations)
Loop fruits.Length {
    MsgBox("Index " . A_Index . " has: " . fruits[A_Index])
}

3. Sorting Array Elements

AutoHotkey doesn't have a direct array.Sort() method, but sorting is easily achieved. Here is my favorite pattern: join the array into a string separated by newlines, use AHK's powerful built-in Sort() function, and split it back into an array!

numbers := [42, 12, 99, 1, 15]

; Step 1: Join into a string with newlines
joined := ""
for index, num in numbers {
    joined .= num . "`n"
}

; Step 2: Sort the string (using numeric option "N")
sortedStr := Sort(joined, "N")

; Step 3: Split it back into an array
sortedArray := StrSplit(Trim(sortedStr, "`n"), "`n")

; Show results!
MsgBox("Smallest: " . sortedArray[1] . "`nLargest: " . sortedArray[sortedArray.Length])
