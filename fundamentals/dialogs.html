MsgBox & Input Dialogs 💬

Hey there! When you build automation scripts, you often need to communicate with your user. Whether it's asking a Yes/No question, asking them to type in some text, or letting them select a file, AHK v2 makes it incredibly easy with built-in dialogs.

1. MsgBox with Buttons and Icons

In AHK v2, MsgBox is a function. If you just pass a string, it shows a simple "OK" dialog. But you can also pass options to add buttons (Yes, No, Cancel) and icons (Warning, Question, Error) and capture what the user clicks!

; Syntax: MsgBox(Text, Title, Options)
; Options: "YesNo" or "YN", "YesNoCancel", "Iconi" (Info), "Icon!" (Warning), "Iconx" (Error)
result := MsgBox("Do you want to continue?", "Confirmation Required", "YesNo Icon?")

if (result == "Yes") {
    MsgBox("You pressed Yes! Moving forward.")
} else {
    MsgBox("You clicked No! Aborting.", "Cancelled", "Iconx")
}

2. InputBox (Getting User Input)

Need the user to type in a name, a search term, or a password? Use InputBox(). It returns an object with a Value (what they typed) and a Result (whether they pressed OK or Cancel).

; Syntax: InputBox(Prompt, Title, Options)
userInput := InputBox("Please enter your name:", "User Settings")

if (userInput.Result == "Cancel") {
    MsgBox("No name entered, operation cancelled.")
} else {
    MsgBox("Welcome, " . userInput.Value . "!")
}

3. FileSelect (Letting Users Choose Files)

Stop hardcoding file paths! It makes your scripts useless on other computers. Use FileSelect() to open a beautiful native Windows file dialog and let the user select a file or folder.

; Syntax: FileSelect(Options, RootDir, Title, Filter)
; Option 1: File must exist. Filter: restrict to Text files.
selectedFile := FileSelect(1, , "Select your configuration file", "Text Documents (*.txt; *.ini)")

if (selectedFile == "") {
    MsgBox("You didn't select anything!")
} else {
    MsgBox("You selected: " . selectedFile)
}
💡 My Golden Rule for Dialogs

Whenever you write a script that processes files, always use FileSelect() or use A_ScriptDir to resolve relative paths. This ensures that your script will run perfectly even if you move it, share it, or compile it into an EXE!
