COM Objects

Control Excel, Word, and other COM-enabled apps directly from AHK.

Advanced 
; Control Excel
excel := ComObject("Excel.Application")
excel.Visible := true
wb := excel.Workbooks.Add()
ws := wb.Worksheets(1)
ws.Cells(1, 1).Value := "Hello from AHK!"
wb.SaveAs("C:\test.xlsx")
excel.Quit()

; Shell operations
shell := ComObject("Shell.Application")
shell.Open("C:\")

; Internet Explorer / MSHTML
ie := ComObject("InternetExplorer.Application")
ie.Visible := true
ie.Navigate("https://autohotkey.com")
Sleep(2000)
MsgBox(ie.Document.title)
