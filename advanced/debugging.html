Debugging Tips 🐞

Hey! In this final lesson, I want to teach you the most important skill in programming: Debugging. Writing code is only half the battle; the other half is figuring out why it doesn't work when it breaks. Let's stop guessing, throw away buggy MsgBox debugs, and learn to inspect our code like professionals.

1. OutputDebug (Your Best Friend)

💡 Stop Using MsgBox to Debug!

Using MsgBox(myVar) to check variable states is a terrible habit. A MsgBox pauses script execution, which ruins game macros, breaks timers, and stops inputs. If you are debugging loops, you'll be stuck clicking "OK" infinitely!

The Professional Way: Use OutputDebug(). It sends text silently directly to the VS Code Debug Console or a tool like Sysinternals DebugView. Your script doesn't freeze, and you get a complete scrollable log!

Loop 5 {
    ; Logs progress silently to the VS Code console
    OutputDebug("Loop index: " . A_Index . " running background scan.`n")
    Sleep(100)
}

2. ToolTip as a Live HUD Inspector

If you are writing a script that tracks coordinates or inspects screen states in real-time, you need a visual HUD. I always use ToolTip() as a temporary floating text box near the mouse cursor to display active data!

; Hit Ctrl+Shift+S to toggle a live mouse coordinate tracker
^+s::
{
    static active := false
    active := !active
    
    if active {
        SetTimer(TrackMouse, 50) ; Run tracker every 50ms
    } else {
        SetTimer(TrackMouse, 0)  ; Turn off timer
        ToolTip()                ; Clear active ToolTip
    }
}

TrackMouse() {
    MouseGetPos(&mX, &mY, &mWin, &mControl)
    winTitle := WinGetTitle("ahk_id " . mWin)
    
    ; Display a floating inspector block right next to the cursor
    ToolTip("Mouse coordinates:`n"
          . "X: " . mX . " | Y: " . mY . "`n"
          . "Active Window: " . winTitle . "`n"
          . "Hover Control: " . mControl)
}

3. The Top 5 Beginner Mistakes & How to Spot Them

If your script behaves weirdly, check this checklist first. 90% of beginner bugs fall into one of these buckets:

The Bug What's wrong The Fix
Wrong Coords Clicking in the wrong place or pixel search failing. You forgot CoordMode! Set CoordMode("Mouse", "Client") and CoordMode("Pixel", "Client").
Assignment `=` myVar = 42 makes a string, not assignment. In v2, always use := for assignment (e.g. myVar := 42).
Unquoted Strings name := Alice looks for a variable, not the string "Alice". Always wrap literal text in double quotes (e.g. name := "Alice").
Scoping issues Variables inside functions are empty/lost. If trying to edit a global variable inside a function, declare global varName first!
Type mismatches "42" == 42 evaluates to false. Convert types explicitly using Integer(), Float(), or String().
