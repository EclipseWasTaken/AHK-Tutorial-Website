OnMessage & Windows Messages 📡

Hey there! Welcome to one of the most powerful system-level features in AutoHotkey: OnMessage. Behind the scenes, Windows communicates with applications by sending millions of "Windows Messages" (integers representing events). Using OnMessage(), your script can intercept these OS-level signals to react to mouse drags, window closures, system shutdowns, and even hardware plug-ins!

What is a Windows Message?

Every time you click, drag, resize, plug in a USB, or turn off your PC, Windows broadcasts a hex code message. For example:

  • 0x0201 ➜ Left Mouse Button Down (WM_LBUTTONDOWN)
  • 0x0010 ➜ Window Close Request (WM_CLOSE)
  • 0x0219 ➜ Hardware Device Changed (e.g. USB insert/remove) (WM_DEVICECHANGE)

1. Dragging a Borderless GUI (The Best UI Trick!)

Standard Windows forms have boring default title bars. If you build a sleek, premium, borderless glassmorphism GUI, you lose the ability to drag and move the window. By intercepting 0x0201 (Left Click Down), you can trick Windows into thinking the user is dragging the title bar, allowing them to drag your borderless window from *anywhere* on the form!

#SingleInstance Force

; Create a borderless, premium GUI
myGui := Gui("-Caption +AlwaysOnTop") 
myGui.BackColor := "13161b"
myGui.AddText("cwhite w250 h100 Center", "`nSleek Borderless App`n`nClick and drag anywhere to move me!`n`nPress ESC to close.")

; Listen for left click down on the GUI
OnMessage(0x0201, WM_LBUTTONDOWN)

myGui.Show()

WM_LBUTTONDOWN(wParam, lParam, msg, hwnd) {
    ; Send the Windows API message 0xA1 (WM_NCLBUTTONDOWN) with parameter 2 (HTCAPTION)
    ; This tricks Windows into starting a window drag!
    PostMessage(0xA1, 2, , hwnd)
}

2. Intercepting Close Requests (WM_CLOSE)

If your script is running complex automation loops or managing system connections, you don't want a sudden GUI close or system restart to corrupt data. You can intercept the close request to ask for confirmation or perform essential cleanup!

; Intercept WM_CLOSE (0x0010)
OnMessage(0x0010, InterceptClose)

InterceptClose(wParam, lParam, msg, hwnd) {
    confirm := MsgBox("Are you sure you want to exit and stop all background macros?", "Confirm Exit", "YesNo Icon!")
    if (confirm == "No") {
        return 0 ; returning 0 discards the message, preventing the window/script from closing!
    }
    ; Let the script exit naturally (returns blank or 1)
}

3. Detecting USB Device Insertion

🔌 Hardware Plug-In Listener

Want your script to automatically run a backup when you plug in a specific USB drive? Or beep when a device disconnects? Intercept 0x0219 (WM_DEVICECHANGE):

OnMessage(0x0219, WM_DEVICECHANGE)

WM_DEVICECHANGE(wParam, lParam, msg, hwnd) {
    ; wParam = 0x8000 (DBT_DEVICEARRIVAL - device inserted)
    ; wParam = 0x8004 (DBT_DEVICEREMOVECOMPLETE - device removed)
    if (wParam == 0x8000) {
        SoundBeep(800, 100)
        SoundBeep(1000, 150)
        TrayTip("Hardware Detected!", "USB Device Connected")
    }
}
