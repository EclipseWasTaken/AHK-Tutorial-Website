Regular Expressions

Regular Expressions (RegEx) are a powerful mini-language for pattern matching. Instead of looking for an exact word, you can look for patterns like "a phone number" or "an email address".

Advanced

RegExMatch() — Finding a Pattern

RegExMatch() searches a string for a pattern. It returns the position (index) where the match starts, or 0 if the pattern wasn't found.

; Let's find the position of a word starting with 'Wo'
pos := RegExMatch("Hello World", "Wo\w+")

if (pos > 0) {
    MsgBox("Found match at position " . pos)
} else {
    MsgBox("No match found.")
}

Extracting Data: The Match Object

Finding the position is nice, but usually, we want to extract the actual text that matched. To do this, we pass a variable with the & (ByRef) symbol. AHK will fill this variable with a Match Object.

; I use &m to get the Match Object back
RegExMatch("My order number is 94821", "\d+", &m)

; m[0] always contains the full matched text
MsgBox("Extracted number: " . m[0])  ; "94821"

Capture Groups: Splitting up matches

If you wrap parts of your pattern in parentheses ( ), RegEx treats them as Capture Groups. The Match Object stores each group separately so you can easily pull out specific pieces of data.

; Parsing a date format: YYYY-MM-DD
RegExMatch("2024-01-15", "(\d{4})-(\d{2})-(\d{2})", &m)

MsgBox(
    "Full match: " . m[0] . "`n" .
    "Year: "       . m[1] . "`n" .
    "Month: "      . m[2] . "`n" .
    "Day: "        . m[3]
)

Named Capture Groups (Best Practice)

Using numbers like m[2] can get confusing in large patterns. You can name your groups using the syntax (?P<name>...).

; Named groups are my favorite way to parse data
RegExMatch("john@example.com", "(?P<user>\w+)@(?P<domain>\S+)", &m)

MsgBox("User is: " . m["user"])      ; "john"
MsgBox("Domain is: " . m["domain"])  ; "example.com"

RegExReplace() — Search and Replace

Instead of just finding text, RegExReplace() replaces all matches with a new string. It returns the modified string.

; Let's censor all vowels in a sentence
result := RegExReplace("Hello World, how are you?", "[aeiou]", "*")

MsgBox(result)  ; "H*ll* W*rld, h*w *r* y**?"

; Strip out everything except numbers
onlyNums := RegExReplace("Phone: (555) 123-4567", "\D", "")
MsgBox(onlyNums) ; "5551234567"

AHK RegEx Flags

AHK uses PCRE (Perl Compatible Regular Expressions). To use flags like case-insensitivity, you prepend them to the pattern string followed by a closing parenthesis ).

FlagMeaningExample
i)Case-insensitive matching"i)hello" matches "HELLO"
m)Multiline (makes ^ and $ match start/end of lines)"m)^start"
s)Dot matches newline (usually . ignores newlines)"s).*?"
