Directives

Start with # and configure script behavior at load time.

DirectivePurpose
#Requires AutoHotkey >= 2.0Enforce minimum AHK version
#SingleInstance ForceKill previous instance on reload
#SingleInstance OffAllow multiple instances
#HotIf expressionStart context-sensitive hotkeys
#HotIfEnd a #HotIf block
#Include filenameInclude another script file
#MaxThreads NMax simultaneous script threads
#NoTrayIconHide the system tray icon
#WarnEnable runtime warnings
#UseHookForce keyboard hook for hotkeys
