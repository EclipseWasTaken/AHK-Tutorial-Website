Script Playground

Write AHK v2 logic and simulate the output in your browser. Uses a full JS-based interpreter — great for learning syntax and logic flow. Windows-specific functions (Send, Run, PixelSearch, WinActivate) require real AHK installed.

ℹ️ What this simulator supports

Variable assignments, math, string operations, loops (Loop N, While, For-in), if/else if/else, arrays, MsgBox/ToolTip output, and all common built-in functions. Tab key inserts 4 spaces in the editor.
